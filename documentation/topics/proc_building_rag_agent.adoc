= Building a RAG agent

Create a {mastra} agent that uses `createVectorQueryTool` to perform semantic search over {brandname}.

.Prerequisites
* An {brandname} Server running with indexed data (see xref:vector-operations[Vector operations]).
* An OpenAI API key for embedding generation and LLM responses.

+
. Register the agent in your {mastra} configuration:
+
[source,typescript]
----
include::../topics/code_examples/rag-mastra-config.ts[]
----
+
. Run with {mastra} Studio:
+
[source,shell]
----
npx mastra dev
----
+
Open `localhost:4111`, select the agent, and ask questions about your indexed data.
